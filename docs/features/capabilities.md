# Capabilities

The Google Client for Salesforce currently supports:

- **File Explorer UI** (Owned by Me / Shared with Me) for fast navigation
- **True Document Previews** (PDF, images, Google Docs) without downloading
- **Flexible Folder Structure**: user-based, record-based, or plain Drive folder
- **Secure Sharing & Access Controls**
- **Public Link Creation**, with optional **organization-domain restriction** to limit access to users in your domain
- **File Versioning** (upload new versions, traceability)
- **Audit & Security Visibility** for sharing and access decisions

## Enterprise Security Layer

Access is enforced through a dedicated **security layer** inside the Google Client, designed for enterprise usage: consistent rules across Salesforce and Experience Cloud, predictable behavior, and alignment with Google Workspace policies.

## What This Means for Your Business

With this approach, organizations can:

- **Reduce Salesforce file storage costs**
- **Maintain compliance and control** with centralized, policy-driven access
- **Avoid personal Gmail accounts** — everything stays within your Workspace
- **Enable collaboration internally and externally**
- **Improve the user experience** with a modern file explorer, previews, and clear sharing UX

No third-party middlemen, no external storage services — just Google Workspace + Salesforce.
