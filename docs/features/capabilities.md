# Capabilities

The Google Client for Salesforce currently supports:

- True Document Previews (pdf, images, docs)
- Secure File Sharing & Access Controls
- Public Link Creation
- File Versioning
- Audit & Security Visibility

## What This Means for Your Business

With this approach, organizations can:

- **Reduce Salesforce file storage costs**
- **Maintain compliance and control**
- **Avoid personal Gmail accounts** — everything stays within your Workspace
- **Enable collaboration internally and externally**
- **Improve the user experience** with modern previews and editing tools

No third-party middlemen, no external storage services — just Google Workspace + Salesforce.
